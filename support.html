Support and user guide

KB Manager is in pre-release. The extension has not yet been submitted to Zoho Marketplace. The documented flow requires a real installation and the necessary Desk permissions.

  1. Install the tested extension into the intended Zoho Desk organization and authorize only the article scopes required by its final manifest.
  2. Open KB Manager from the Desk top band; if absent, inspect the overflow menu. Load only the article scope you intend to maintain.
  3. Inspect link results. Confirmed HTTP failures and checks blocked by authentication or a network restriction need different follow-up; an inconclusive result is not proof the URL is broken.
  4. For repeated text or URL edits, enter the search and replacement values, create a preview, and review each affected article. Apply only the intended changes. A later edit invalidates a stale preview; generate a fresh one.
  5. Review per-article apply outcomes. Use Undo only for eligible successful changes while their recovery record remains available. If another editor changed an article, review it manually instead of overwriting the newer content.
  6. Choose an age threshold for the article review report. Export CSV as needed. CSV is a report, not a full knowledge-base backup.

Troubleshooting

  • Missing article permission: ask the Desk administrator to verify your article role and the extension connection scopes.
  • OAuth scope mismatch: reauthorize the actual KB Manager connection after its scope list has been corrected. The predecessor ticket extension's authorization is insufficient for article operations.
  • Link check blocked: test the URL through your normal authorized workflow. Do not bypass login, Cloudflare, or a paywall.
  • Partial run: review successful and failed rows and refresh source content before a new preview. Do not reapply a completed run blindly.
  • Rate limit or quota response: stop, preserve the exact error and any reset time, then resume only when the limit permits it.

Support and privacy contact: support@atesensoftware.com. There is no guaranteed response-time SLA. Provide the extension version, data center, timestamp/time zone, action, redacted error, and article IDs only when necessary. Never send access tokens, OAuth secrets, full customer exports, or personal contact information.

Uninstall and recovery

The organization-specific recovery journal persists in browser localStorage with no automatic expiry. Keep the same browser profile and extension origin when recovering a run. Use the journal deletion control only after reviewing the run and confirming recovery is no longer needed; otherwise clear the extension origin's browser/site data. Deleting that record removes this extension's undo capability. Exported CSV reports are not a content backup. Uninstalling does not guarantee browser-storage cleanup and does not delete downloaded files.
