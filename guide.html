Workflow guide

This pre-release guide describes the extension workflow. Live installation in the EU trial organization remains pending account access.

1. Load and inspect

Open KB Manager in the Desk top band and load accessible articles. Choose the intended scope. Source article permissions continue to apply.

2. Review links

Inspect article links. External HTTP checking is opt-in and sends requests from your browser. HTTP 404/410 indicates a broken destination; authentication restrictions, CORS failures, and other inconclusive results need follow-up. A quota or rate-limit response stops further checking. The scan is not a scheduled background service.

3. Preview replacements

Enter the text to find and its replacement, create a preview, and check each changed article. The source content and modification time are checked again before a write. If the source changed, refresh and create another preview. Do not assume a multi-article run is atomic.

4. Apply and inspect results

Apply only the intended changes. Review successful, failed, uncertain and conflicting results. Preserve the recovery journal while you need undo. A failed or interrupted call can require manual review of the article before retrying.

5. Undo eligible changes

Use the recovery action in the same browser profile and organization. The extension checks the article's content and available modification-time guard before restoring original content. A later edit blocks automatic restoration. Recovery data persists in localStorage until removed; journal deletion permanently removes this extension's recovery record.

6. Review article age and export

Set an article age threshold and inspect the resulting maintenance queue. Export CSV when needed. Protect downloaded reports and delete them according to your organization's policy. They are not full content backups.
